# Лабораторная работа №3 — вёрстка второго экрана

## Что сделано

В отдельном Flutter-проекте реализованы два экрана: каталог занятий и детальная
карточка выбранной темы. Нажатие на элемент первого экрана открывает маршрут
`/content/:id`; идентификатор передаётся в URL, по нему выбирается нужная модель
`Lesson` и отображается развёрнутая информация.

## Выполнение задач

| Задача | Выполнение |
| --- | --- |
| Второй экран | `DetailsScreen` содержит `AppBar`, большое изображение, заголовок, описание и поясняющий текст. |
| Связь с первым экраном | В `HomeScreen` каждая строка списка вызывает `context.push('/content/<id>')`. |
| Навигация | `GoRouter` описывает маршруты `/home` и `/content/:id`; неизвестное значение не создаётся, так как используется только ID из списка. |
| Вёрстка | `SingleChildScrollView`, отступы и `ClipRRect` обеспечивают читаемую прокручиваемую карточку и скруглённое изображение. |

## Запуск

```powershell
flutter pub get
flutter run -d edge --release
```
